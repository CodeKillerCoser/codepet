# 任务卡片交互

## 当前数据与展示

桌宠只消费 Pet Gateway 的 `PetTask`。后端 `pet_gateway/projection.rs` 负责来源事件到任务的投影；前端 `pet/model.ts` 负责最新排序、关闭历史和连接错误。原 `activity.ts` 的 `PetEvent` 归并已删除。

桌面模式使用 `PetActivityGroups.svelte`，按等待交互、进行中、已完成分组：waiting-approval/waiting-input/unknown/failed 属于等待交互，running 属于进行中，completed/interrupted 属于已完成。每组可展开，组状态存于宿主，模式切换保留。顶部模式使用 `pet/NotchPet.svelte` 的横向任务列表，固定顶栏，列表单独滚动。

标题、Agent 标识、实际状态与最近更新时间来自任务字段；顶部列表用左侧 provider 图标标识 Agent，不重复显示右侧名称徽标；时间为 updatedAt，不是持续运行时长。Markdown 经过统一净化；桌面消息保持一行，顶部最多两行，链接仍可打开。顶部缺少正文时明确提示“尚未收到回复内容”。

`summary` 是活动摘要：有助手回复时优先显示回复，否则可显示提示词、错误或工具描述、命令、文件路径。工具 hooks 无回复字段时仍能更新进展；新轮清空旧摘要并忽略上轮回复，空事件保留本轮摘要。参见 [活动摘要规约](../60-rules/pet-activity-summary.md)。

## 操作与边界

支持隐藏任务、桌面清除已完成任务、模式切换、打开主窗口、角色互动。隐藏记录在该任务有更新前有效，两套 UI 共用。当前不提供来源会话激活、回复、审批或打断按钮；后端 Agent 和远程控制能力不等于桌宠已接入控制协议。

顶部的 completed/interrupted 按 provider 归组，保留一个“已完成”标题。组收起时，垂直滚轮循环切换顶层任务，遍历整组而非仅三张可见堆叠层；不同组分别记忆选择，展开后恢复原排序和正常列表滚动。展开再收起保留所选任务；任务被隐藏、恢复运行或移出该组后回到组内第一项。单条任务、横向手势和捏合缩放不拦截。触控板微小增量累加到阈值才翻页，连续翻页间隔至少 160ms；减少动态效果偏好关闭堆叠位移动画。`NotchPet.svelte` 负责滚轮、展开与任务分组，`planeStackMotion.ts` 只负责 Plane Cards 运动，不改变共享任务顺序或协议。

收起的组使用纵向轨道：卡片平面始终与屏幕平行，位置沿上下和纵深方向循环，以平移、等比缩放、连续文字透明度和遮挡层级呈现新卡上浮、旧卡退后。缩放沿用原堆叠的 600px 透视与 18px 层间距，卡片宽度限制在原宽的约 94.3%–100%，不扩大前后层的宽度差或改变窗口基础宽度。弹簧驱动连续进度，反向输入保留当前位置与速度，停止后吸附到整张卡片。虚拟三槽轨道最多渲染三张卡片，后侧接缝淡出换入，两个任务使用对向槽位。静止时恢复原来的向下 11px/22px 紧凑堆叠，不保留上方露出或额外轨道留白；只有两个整数停靠点之间才连续混入环绕轨迹，停靠前后混合权重及其斜率归零，避免开始/停止时跳变。卡片高度与原堆叠占位固定，避免每帧触发原生窗口缩放；窄屏保留标题、状态与两行消息的空间。展开时取消动画、恢复原列表布局；偏好减少动态效果时直接切换。

## 风险与验证

新增动作需检查协议、键盘焦点、窄屏可见性和原生透传。隐藏堆叠卡不得拦截鼠标；模式切换不可产生第二条任务订阅。运行 `frontend/lib/pet/model.test.ts`、`activityGroups.test.ts` 及顶部/桌面分组浏览器 QA，原生拖动和透传另在目标系统验证。

`npm run test:pet:ui` 使用真实组件和模拟原生 IPC，覆盖整组轮换、正反向循环、触控板增量、分组独立性、展开后的原生滚动、隐藏/恢复任务、键盘切换及窄屏布局。`npm run test:pet` 检查共享模型和状态机。浏览器 QA 不能替代 macOS 原生 WKWebView 的真实触控板惯性手感验收。

`npm run test:pet:stack` 对真实组件使用可控浏览器时钟，按浏览器测试时钟的 16ms 帧间隔保存前进、反向及中途反向的截图和矩阵数据，逐帧检查平面朝向、位移/缩放/文字连续性、顶栏和容器稳定性，并检查展开后的原生滚动与减少动态效果。产物在 `artifacts/pet-plane-stack-qa/`；GitHub Pet UI quality 保留截图和报告。该验收使用模拟 IPC，尚未覆盖原生 WKWebView 的合成与触控板惯性。
