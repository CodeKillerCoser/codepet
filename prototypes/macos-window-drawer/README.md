# macOS 窗口抽屉 Demo

独立的原生 AppKit 原型，不读取正式桌宠的任务、账号或设置。0.3 版收起后只保留顶部条，不通过最小化收起；展开后真实窗口位于黑色容器的正文内部，四周保留黑色留白。当前管理一个窗口。

## 运行

双击本目录 `open.command`。首次没有构建产物时会调用本机 Swift 编译器构建；也可以运行：

```sh
prototypes/macos-window-drawer/build.command --open
```

产物：`artifacts/window-drawer-demo/Code Pet Drawer.app`，标识为 `com.codepet.window-drawer-demo`，本机 ad-hoc 签名。

## 体验

1. 点「先体验可编辑示例」，窗口被隐藏，顶部保留黑色猫咪入口，不生成 Dock 中的最小化窗口。
2. 鼠标离开入口再移入，停留 200ms 展开。黑色容器和正文一起展开，原窗口位于正文的透明开孔内。可以输入、选择文字、滚动和点「点我 +1」。
3. 移开入口及窗口范围 650ms 后隐藏正文和原窗口，只留顶部条；鼠标按住时暂停收起。菜单栏也提供「收起到顶部」。
4. 点「固定」持续展开，适合输入及操作菜单、文件选择器；再次点击恢复自动收起。
5. 拖动顶部区域可沿当前屏幕左右移动，完整黑色外框与里面的窗口跟随。
6. 点「释放」恢复窗口原位置、尺寸和最小化状态；点「退出」先尝试恢复窗口。菜单栏猫咪图标也提供这些入口。

控制其他 App：点「开启辅助功能权限」，在系统设置中开启 **Code Pet Drawer**，回来点「刷新窗口」，再选择一个普通窗口。授权由用户自行完成。没有授权时内置示例仍可用，示例成功不代表外部 App 已兼容。无需屏幕录制权限。

## 限制与恢复

- 收起不进入 Dock，也不隐藏整个 App。内置示例通过 `NSWindow.orderOut` 隐藏，保持窗口对象、内容和非最小化状态；目前为即时切换，尚未加入连续上滑动画。
- 外部 App 通过 AX 尝试把窗口停放到全部显示器之外，并回读实际 frame。若系统钳制位置导致仍有任何部分可见，则恢复原位置并提示不支持；不接受残留边缘，不退回最小化，也不连带隐藏其他窗口。本机尚未授权，外部兼容性未验收。
- 容器使用原生 NSPanel，顶栏和黑色边框位于前景，正文留透明开孔；鼠标在窗口区域时整块外框透传，事件直接到原窗口。示例用本进程 NSWindow，其他 App 通过 AX 控制位置/尺寸。点击原窗口后按系统规则激活其 App。
- 原窗口仍保留自己的原生标题栏、控件和阴影，并非 WebView 子视图；无须镜像或转发鼠标键盘。窗口实际最小尺寸无法容纳时拒绝展示并尝试恢复。
- 切换到无关 App 时收起容器，避免透明开孔显示其他窗口；「固定」只暂停鼠标移出的自动收起。
- 当前桌面的普通窗口为测试范围。全屏不接受绑定，不跨 Space 搬运；切换 Space 时尝试收起。尚未验证所有 App、Stage Manager 和多屏硬件。
- 外部菜单、文件选择器、输入法候选框没有通用自动归属检测，操作前请点「固定」。文字持续输入时若移走鼠标也会收起。
- 正常退出恢复窗口。内置示例随 Demo 进程退出；外部屏外停放若发生异常退出，应重新启动 Demo 使用「恢复上次收纳窗口」，它会查找候选并要求用户确认。屏外窗口不能依赖 Dock 自动恢复原位置。
- 持久化仅在本 Demo 的 UserDefaults 中保存恢复所需的 PID、进程启动时间、窗口标题、原 frame 和最小化状态。新绑定会覆盖上一次恢复记录。

## 验证

`build.command` 同时编译并运行纯逻辑测试，覆盖悬停取消、离开延迟、拖动和固定保护、手动关闭抑制、坐标换算、屏幕边界，以及正文包含窗口、顶栏不重叠和原生输入区域。

```sh
'artifacts/window-drawer-demo/Code Pet Drawer.app/Contents/MacOS/CodePetDrawer' --smoke
```

原生 smoke 在自己的示例窗口上验证实际外框包含窗口、顶栏分离、开孔像素透明、绑定、展开、固定、移动跟随、隐藏、再次展开、内容保留及释放恢复。绑定后与收起后都断言 `isVisible == false` 且 `isMiniaturized == false`，防止用最小化冒充顶部收纳。它不会操作其他 App，也不验证系统授权或外部 AX 支持。真实外部窗口的测试需要用户授权后另行执行。

设置 `CODEPET_DRAWER_PREVIEW` 为 PNG 绝对路径后执行 smoke，可导出本应用原生视图的合成预览。`artifacts/window-drawer-demo/embedded-preview.png` 为本机生成的示例预览，它不是桌面合成器截图。单独截取容器 NSPanel 时正文会显示为空，因为真实窗口位于独立原生窗口中。

同时设置 `CODEPET_DRAWER_COLLAPSED_PREVIEW` 可导出收起后的真实顶部 NSView 渲染，本机产物为 `artifacts/window-drawer-demo/collapsed-preview.png`。

设计依据及后续验证范围见 [调研方案](../../knowledge/10-architecture/macos-external-window-drawer-proposal.md)。
