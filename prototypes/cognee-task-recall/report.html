让一次工作留下可召回的上下文

Cognee 最小验证：以真实 TaskRun 快照检查实体抽取、文档替换、多路召回和图浏览。原始账本只读，控制性改动只发生在实验副本。

实验配置对照

使用同一批业务快照。旧方案到 LLM 方案同时更换抽取器、embedding、提示词和分块；同一套 LLM 配置的两个输入版本用于观察进度历史的影响。

LLM 实际抽取与原文证据

证据逐字匹配只能发现引用错误，不能证明关系推断正确。模型自述的实施或验证不等于人工验收。知识文档由首次抽取的实体和关系直接排版，没有再次调用模型；原始回执另含受控更新。
