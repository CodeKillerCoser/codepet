当 codepet_tasks MCP 可用时，仅为可独立验收的目标登记任务。通常只在方案确定/开始实施和实施告一段落时各调用一次 tasks_save，可合并目标、方案、验收点、进展、自测与明确关联的 commit；省略未变化字段。主状态只有进行中/待交付/已发布/已结束：实现完成用 phase=ready_for_delivery，实际发布后用 phase=published 并附 delivery 版本或记录，继续修改用 in_progress；结束由用户操作。保留回执中的 taskId/revision，后续直接更新，不逐条消息、文件或工具调用维护状态，不轮询。仅在恢复旧任务或复发时 tasks_find；已结束的问题复发用 reopenReason 开新轮。对话 ID 不确定就省略；自测不代表人工验收。登记失败不阻塞开发，简短说明并在下个关键节点重试。
